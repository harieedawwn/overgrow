OVERGROW — SHARED CONTRACT (every module follows this exactly)

GAME
2D top-down auto-shooter roguelite for the browser, Vietnamese UI. Player = a small amber seed-spirit. Enemies = "Sương Độc" mold blobs that bloom into flowers when defeated, so the map fills with flowers where the player fought. A living skill tree grows from how the player plays (4 branches); two branches meeting create a synergy. One season (run) lasts up to 15:00; the final boss "mother" at 15:00 clears Act 1. Death or clear = Winter: roots (permanent currency) are gained, the tree sheds its leaves, the next season starts stronger. Daily Seed: same seed for everyone each day, shareable result text. Offline growth up to 8 h.

TECH
- Plain JavaScript, no build step, no ES modules, no libraries. Opens by double-clicking index.html (file://) and works on GitHub Pages.
- Every JS file is wrapped: (function (OG) { ... })(window.OG = window.OG || {});
- Script order in index.html: js/core.js, js/tree.js, js/world.js, js/meta.js, js/audio.js, js/render.js, js/treeview.js, js/ui.js, js/main.js
- core.js loads first, so modules may call OG.game.addUpdate / addRender and OG.bus.on at load time. Nothing else runs at load time. js/main.js calls OG.boot().
- Each module keeps its tunables at the top of its file in OG.cfg.<module> = {...}.
- Node tests: tests/test_<module>.js, run with: node tests/test_<module>.js ; set globalThis.window = globalThis, load the module source with vm, stub only the APIs below that the module uses. Exit code 0 = pass.

CORE API (js/core.js)
OG.bus.on(name, fn) · OG.bus.off(name, fn) · OG.bus.emit(name, data)
OG.game.state: 'title' | 'run' | 'levelup' | 'paused' | 'winter' ; OG.game.setState(s) emits state:change {from,to}
OG.game.addUpdate(fn(dt), order) — every fixed tick, dt = 1/60 s, only while state === 'run'
OG.game.addRender(fn(ctx, alpha, realDt), order) — every animation frame, in every state
OG.boot() — creates canvas, input and loop, emits boot; idempotent
OG.canvas, OG.ctx — <canvas id="game"> inside <div id="app">, sized to the window × devicePixelRatio (cap 2)
OG.view = { w, h, dpr } in CSS pixels; emits resize {w,h,dpr}
OG.input = { move:{x,y} (length ≤ 1), dash (true for one tick after a press), pressDash(), stick:{active,ox,oy,x,y} }
  keyboard WASD/arrows, Space/Shift = dash, Esc/P = pause toggle; touch = floating joystick on the left 60% of the screen; mouse = hold left button to move toward the pointer. Pointers starting on elements with class .ui-block are ignored.
OG.rng(seed) → function returning floats in [0,1) ; OG.hashSeed(string) → uint32 ; OG.rand = current run RNG
OG.save.load() → object | null ; OG.save.write(obj) ; key 'overgrow.v1' ; never throws
OG.fmt(n) → Vietnamese short number with comma decimals: 999 · 1,2 N · 3,45 Tr · 5,6 Tỷ · 7,8 NTỷ · 1,0 Rừng (1e15) · 1,0 Đại Ngàn (1e18) · 1,0 Thiên Hà (1e21)
OG.fmtTime(sec) → "mm:ss" ; OG.clamp(v,a,b) ; OG.lerp(a,b,t) ; OG.dist2(ax,ay,bx,by)

ENEMY KINDS (world simulates, render draws)
spore r8 fast weak · mold r13 standard · brute r24 slow tanky · spitter r12 keeps distance and shoots hazards · core r40 mini-boss at 3:00 6:00 9:00 12:00 (drops 3 heal pickups, grants 1 level) · mother r70 final boss at 15:00, phases at 66% and 33% hp, its death = Act 1 clear.
World bounds: -2000..2000 on both axes.

BEHAVIOR TRACKING (world calls OG.tree.track(branch, amount) every tick)
fire += seed damage dealt to enemies within 180 px of the player · wind += distance moved while any enemy is within 220 px · root += xp collected · stone += dt while player.still > 0.5 s, plus damage taken

FLOW
boot → meta.init → ui title (offline dialog if offline:gain). Play → meta.startRun → world.reset, tree.reset(bonus), setState('run'), run:start.
Level-up → tree emits levelup:offer and setState('levelup') → ui shows cards → ui calls tree.choose(id) → next queued offer or setState('run').
player:dead (unless revived) or boss:dead {kind:'mother'} → meta.endRun → setState('winter') → render.zoomOut(3) → winter:show → ui winter screen.

ART DIRECTION "storybook garden at dusk"
Flat painted shapes with dark ink outlines, like a picture book. No gradients, no glow, no neon, no emoji in the UI. Palette: ground #2E3A2F · grass #5E7D4A · paper #F2E8D0 · ink #1F2420 · player amber #F4B942 · blight #7B6F8A with outline #3B3346 · plus the 4 branch colors. Fonts: 'Baloo 2' (titles, numbers) and 'Be Vietnam Pro' (text), self-hosted, Vietnamese subset. All player-facing text is Vietnamese.

BALANCE TARGETS
A level-up at least every 60 s · enemy hp ×2 every 90 s, dmg ×1.5 every 90 s · first season usually ends at 6–9 min · power rises in steps (synergy jumps ×1.5–×3) against the smooth enemy curve, so play alternates pressure and breakout · with roots a good build clears 15:00 after about 5–8 seasons.
